# Rag-insurance-Agent

Gradio RAG-based Insurance Agent chatbot.

- Run locally in a Python venv (`.venv`).
- Uses local `sentence-transformers` embeddings and `chromadb`.
- `chroma_db/` and `.venv/` are gitignored by default.

To push to GitHub (after creating the remote repository):

```bash
git remote add origin https://github.com/<USERNAME>/Rag-insurance-Agent.git
git branch -M main
git push -u origin main
```
